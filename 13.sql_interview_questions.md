# SQL Interview Practice — Joins & Classic Query Problems

Questions only — no answers. Write the query, then check it against a real DB (or your `12.DBMS.md` notes) if unsure.

## Reference schema

Use this schema for every question below unless a question defines its own.

```sql
Employees(emp_id, name, salary, dept_id, manager_id, hire_date)
Departments(dept_id, dept_name, location)
```

- `manager_id` references `Employees.emp_id` (an employee's manager is another employee; top-level managers have `manager_id = NULL`)
- `dept_id` in `Employees` may be `NULL` (employee not yet assigned to a department)
- Assume duplicate names are possible; `emp_id` is always unique

1. List all employees along with their department name. What happens to employees with `dept_id = NULL` if you use an INNER JOIN vs a LEFT JOIN?
```sql 
select * from Employees, Departments
where  Employees.dept_id = Departments.dept_id
```
INNER JOIN returns only rows where the join condition is TRUE.
*NULL = anything* is never TRUE, it's UNKNOWN.
So, employees with dept_id = NULL are excluded from the result. They will disappear.

So Use LEFT JOIN -> 
```sql
SELECT e.name, d.dept_name
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.id;
```

2. Find all departments that have **zero** employees.
```sql 
SELECT d.dept_id, d.dept_name, e.dept_id
FROM Departments d
LEFT JOIN Employees e ON e.dept_id = d.dept_id
WHERE e.dept_id IS NULL;

SELECT ... 
FROM table1
WHERE EXISTS (subquery)
-- If subquery returns 1 or more rows -> EXISTS is TRUE, the outer row is kept.
-- If subquery returns 0 rows -> EXISTS is FALSE, the outer row is discarded.

SELECT d.dept_name
FROM Departments d
WHERE NOT EXISTS (
    SELECT 1 
    FROM Employees e 
    WHERE e.dept_id = d.dept_id
);

SELECT d.dept_id, d.dept_name, COUNT(e.emp_id) AS employee_count
FROM Departments d
LEFT JOIN Employees e ON e.dept_id = d.dept_id
GROUP BY d.dept_id
HAVING employee_count = 0;
```

9. Find all employees who earn **more than their manager**.
```sql
SELECT
 e.name employee_name,
 m.name manager_name,
 e.salary employee_salary,
 m.salary manager_salary
FROM Employees e
JOIN Employees m ON e.manager_id = m.emp_id
where e.salary > m.salary;
```

17. Find employees whose salary is **above the average salary of their own department**.
```sql
SELECT e.name, d.dept_name, e.salary
FROM Employees e
JOIN Departments d
  ON e.dept_id = d.dept_id
WHERE e.salary > (
    SELECT AVG(salary)
    FROM Employees
    WHERE dept_id = e.dept_id
);
```
