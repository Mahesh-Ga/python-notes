11. 
Optimistic Row Locking 
Automatic row Lcoking 
user 1 -> update the row -> locks the row -> commit -> release
user 2 -> delete the same row -> will wait to release -> delete

Pessimistic Row Locking 
- manual row locking in advance before issuing update/delete
- To lock row, select statement with `FOR UPDATE` clause
- locks are automaticaally released when you rollback/commit
```sql
select * from emp
where id = 10
FOR UPDATE wait 60; -- 60 seconds
```

17. GROUP BY( GROUPING ) (SORTING)
Whatever is in your SELECT can ONLY be:
    a. Columns that are in your GROUP BY
    b. Aggregate functions like COUNT(), SUM(), AVG(), MIN(), MAX()
```sql
SELECT city, COUNT(*) 
FROM users 
GROUP BY city;
-- city is in GROUP BY, COUNT(*) is aggregate -> OK

SELECT city, name, COUNT(*) 
FROM users 
GROUP BY city;
-- name is NOT in GROUP BY and NOT an aggregate -> ERROR
```

```sql
SELECT city, COUNT(*) 
FROM users 
WHERE age > 18        -- filter rows first
GROUP BY city
HAVING COUNT(*) > 5;  -- filter groups after
ORDER BY COUNT(*) DESC;
```
